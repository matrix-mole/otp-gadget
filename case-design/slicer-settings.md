# PrusaSlicer Settings

Export from Fusion 360 as **3MF**, component only (hide electrical parts before export).

| Setting | Value |
|---|---|
| Layer height | 0.2 mm |
| Infill density | 20–30% |
| Infill pattern | Gyroid or Honeycomb |
| Perimeters (walls) | 3–4 |
| Top/bottom layers | 4–5 |
| Supports | Enabled (touching buildplate only) |
| Print speed | 40–50 mm/s |
