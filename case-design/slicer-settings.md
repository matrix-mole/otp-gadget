# PrusaSlicer Settings

Settings used on the original prints. Both shells, 0.4 mm nozzle.

| Setting | Value |
|---|---|
| Layer height | 0.2 mm |
| Infill density | 25% |
| Infill pattern | Gyroid |
| Perimeters (walls) | 4 |
| Top/bottom layers | 4 |
| Supports | Enabled, everywhere |
| Print speed | slicer default (untouched) |

Notes:

- **Supports everywhere.** Tested with and without; the supported version came out noticeably cleaner.
- **Infill pattern.** Gyroid was used, but the case is mostly thin shell — pattern barely matters here.
- **Re-exporting from Fusion 360.** Export as **3MF**, component only (hide electrical parts before export).
