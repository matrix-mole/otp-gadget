# Case design

3D-printed enclosure for the OTP gadget. Two parts (top and bottom) screwed together, designed in Fusion 360.

## What's in this folder

**Public (ships in the open-source repo):**

- [`README.md`](README.md) — this file
- [`slicer-settings.md`](slicer-settings.md) — the slicer settings used to print the case. Useful for anyone slicing the supplied `.3mf` files, or designing their own enclosure with similar tolerances.
- [`BEFORE-PRINT-CHECKLIST.md`](BEFORE-PRINT-CHECKLIST.md) — sanity checks before hitting print. Saves filament.

**Paid Builder Pack (small one-time purchase on Gumroad, linked from [matrixmole.com/products/otp-gadget](https://matrixmole.com/products/otp-gadget)):**

- `Case bottom.3mf` — printable bottom shell
- `Case top.3mf` — printable top shell
- `Case-slice-file.3mf` — pre-arranged slicer project file

The `.3mf` files are the only CAD shipped at all — they're the unique design work. Buying them saves you the enclosure design phase. If you'd rather design your own case from scratch, the public parts list ([`docs/parts-overview.md`](../docs/parts-overview.md), [`docs/order-checklist.md`](../docs/order-checklist.md)) and assembly docs give you everything you need to fit your own enclosure to the components.
